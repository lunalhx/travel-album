# 独立旅行相册

默认相册是「年份 · 城市」，同一城市同一年不同日期的零散照片自动合并，页面按日期分段。

需要单独保留一段完整经历时，在 `special-albums.json` 添加定义，再运行导入脚本：

```json
[
  {
    "id": "你的独立相册英文标识",
    "title": "2026 · 你的旅行名称",
    "city": "重庆",
    "photoIds": ["填写 albums.json 里已有照片的 id"],
    "coverId": "选中的照片 id",
    "story": "可选旅行记录"
  }
]
```

这里只是格式说明，不代表已经创建任何旅行。当前定义为空，保留用户真实的两本年度城市相册。

独立相册使用已有展示图，同一照片可以出现在年度册和独立册，不会复制图片文件。照片总数按唯一照片计算。
目前导入配置包含重庆和兰州；新增城市时在 `album_model.py` 的 CITY_INFO 配置城市名称、英文标识和省级行政区代码。
地图根据相册的 provinceCode 归档，不依赖 GPS。区县与景点可写到记录或照片说明中。
